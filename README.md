# Regenerative Braking System for Affordable Electric Vehicles

### BITS Pilani | SOLVE Funded Engineering Project

A simulation-driven engineering project focused on regenerative braking and energy recovery for affordable electric vehicles.

---

## Overview

Regenerative braking is a technology that enables electric vehicles to recover kinetic energy during deceleration and convert it into electrical energy for storage. This project explores the modelling and simulation of a regenerative braking system with a focus on energy recovery, braking performance, and its potential application in affordable electric vehicles.

The project involves the development of computational models using Python and MATLAB to study the behaviour of the system under different operating conditions.

## Project Objectives

- Develop a computational model of a regenerative braking system.
- Analyse energy recovery during vehicle deceleration.
- Study the influence of operating parameters on braking performance.
- Implement and evaluate the model using Python and MATLAB.
- Explore the feasibility of regenerative braking solutions for affordable EVs.
- Establish a foundation for further development, testing, and validation.

## Simulation Framework

The project currently incorporates two simulation implementations:

### Python Simulation
A simplified computational model developed using Python and Google Colab, based on preliminary system information and assumptions.

### MATLAB Simulation
A more detailed computational model developed in MATLAB, incorporating additional system parameters and modelling considerations.

Both implementations investigate the same underlying physical system through different modelling approaches.

Differences in simulation outputs are being analysed in the context of model assumptions, parameter selection, and numerical implementation.
